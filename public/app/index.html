❓ Guide & Formules SPF


      

        
✅
Formules officielles — validées SPF 10/06/2026

        
f2204 = f2069 + f2200 + f2201
f2063 = f2060 + f2062 + f2068  ← CODE 400 = rémunérations uniquement (sans f2204)
f2059 = f2063 + f2204           ← Total contrôle XML (r8012/r9013) = 400 + frais propres

v0020 = f2009 = r8011 = r9012 = N° séquence
r8012 = r9013 = f2059
r9010 = 3   (1 Aangifte)
r9011 = 5   (1 Aangifte + 1 fiche)

Validé : Référence 135750 · Identification 2503 · 10/06/2026 ✅

      


      

        
⚠️
Pièges courants

        
Saisir les montants avec décimales explicites : 3900.00 et non 3900 pour éviter les erreurs d'arrondi IEEE 754.

        
N° séquence : format YYxx (2501, 2502…). Doit être unique par année et ≤ 99999.

        
Modificatif (typeEnvoi=1) : uniquement si la fiche a déjà été ACCEPTÉE par le SPF.
